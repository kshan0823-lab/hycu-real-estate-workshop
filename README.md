# HYCU 부동산학과 | AI 바이브코딩 실전 특강

부동산학과 수강생이 중개·마케팅·시장조사·금융·도시정비·개발·투자·법률·경매·권리분석 업무를 ‘한 문장 요청 → 화면 확인 → 한 가지 수정’의 흐름으로 직접 연습하는 독립형 교육 페이지입니다.

## 바로 보기

이 폴더에서 아래 순서로 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 안내된 주소를 열면 됩니다. 결과 확인용 미리보기는 다음처럼 실행합니다.

```bash
npm run build
npm run preview
```

## 포함된 기능

- 시작 준비, 일정표, 필수 6단계, 선택 실습, 마무리 흐름
- 중개 상담 타이머부터 투자·경매 현장 편집까지 이어지는 6개 필수 실습의 완료 체크와 `필수 n/6` 진행표
- 브라우저 새로고침 뒤에도 이어지는 진행상태 저장과 초기화
- 앱 주제 칩·직접 입력·주제가 반영된 요청문 만들기
- 요청문 복사 버튼과 복사 완료 표시
- 5분 타이머 미리보기
- 한순이가 위·아래 스크롤 방향에 맞춰 가볍게 움직이며 단계별 안내를 보여 주는 캐릭터
- 막혔을 때 여는 도움말 대화상자, ESC·배경 클릭 닫기
- 1440px·768px·390px 화면을 고려한 반응형 구성
- 제공받은 HYCU 로고·심볼·캠퍼스 공간 사진·한돌이·한순이 이미지 반영

## 자료를 바꾸는 방법

강의 내용은 `src/data/lessons.ts`에 모아 두었습니다. 필수 실습 문장, 성공 기준, 수정 문장, 선택 실습, 일정표를 이곳에서 바꿀 수 있습니다.

## 자료·권한 원칙

공개 참고 페이지의 학습 흐름과 상호작용 방식만 참고하고, 원문 본문·사진·영상·ZIP·강사 소개·로고·전용서체는 포함하지 않았습니다. 실제 사진·영상·문서를 추가할 때는 사용 권한과 개인정보 포함 여부를 먼저 확인하세요.

## 실제 AI·파일 작업에 대한 안내

이 페이지는 수업용 요청문과 확인 기준을 제공하는 안내판입니다. 실제 AI 연결, Word 문서 만들기, MP4 만들기, 외부 공개는 별도의 도구·파일·계정·사용자 승인이 필요합니다.
