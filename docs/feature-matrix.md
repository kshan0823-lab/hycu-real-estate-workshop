| 상단 바로가기와 섹션 점프 | 준비·일정·필수·선택 메뉴와 앵커 | 메뉴 클릭 | PASS | 독립 메뉴 문구 |

| 일정표 | 160분 흐름과 쉬는 시간 포함 | 일정 섹션 확인 | PASS | 독립 일정 문구 |

| 요청문 복사 | 클립보드 우선, 실패 시 대체 복사 | 각 복사 버튼 클릭 | PASS | 서버 전송 없음 |
