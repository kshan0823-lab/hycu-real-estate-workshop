## 검수 기준

- 필수 실습 6개가 보이는가
- 각 요청문이 복사되는가
- 앱 주제를 고르면 문장이 바뀌는가
- 완료 체크와 `n/6`이 바뀌고 새로고침 뒤 유지되는가
- 초기화가 동작하는가
- 도움말을 열고 ESC·배경 클릭으로 닫을 수 있는가
- 선택 실습이 펼쳐지고 닫히는가
- 작은 화면에서 가로로 잘리지 않는가
- 빌드와 타입 확인이 끝나는가
