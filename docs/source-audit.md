# 공개 참고 자료 확인 기록

기준일: 2026-11-09

## 1. 기능 참고 페이지

- 주소: https://vibecoding-class-2-1108.vercel.app/
- 확인 방법: 공개 브라우저 화면과 접근성 정보로 위에서 아래까지 확인
- 확인된 구조: 상단 고정형 바로가기, 히어로, 준비 섹션, 시간표, 필수 실습 6개, 선택 실습, 마무리, ‘막혔어요’ 도움말
- 확인된 상호작용: 앵커 이동, 복사 버튼, 앱 주제 칩과 입력, 완료 체크, 필수 `n/6` 카운트, 접기·펼치기, 도움말 버튼
- 확인된 학습 흐름: 타이머 → 내 앱 → 대화 기록 대시보드 → 글·사진·문서 → 타이포 모션 → 영상 편집
- 이번 페이지의 부동산 응용: 중개 상담 → 현장기록 앱 → 시장조사·권리분석 → 부동산 마케팅 → 도시정비·재개발·재건축 → 투자·경매
- 확인되지 않은 범위: 서버 내부 처리, 개인별 추적, 원본 파일의 실제 권리, 비공개 강의 운영 기능
- 조치: 확인된 기능과 학습 순서만 독립 문구로 다시 작성했고, 원문 다운로드·미디어 링크·강사 소개는 넣지 않았습니다.

## 2. HYCU 공식 홈페이지

- 주소: https://www.hycu.ac.kr/user/index.do
- 확인된 사실: 학과소개 안에 융합경영대학의 부동산학과가 표시되고, 학사안내·대학알림·대학소개·대학생활·미디어·홍보로 이어지는 메뉴 구조가 확인됩니다.
- 반영한 방향: 상단 메뉴가 분명하고, 교육 안내가 단계별로 읽히며, 아카데믹한 여백과 정보 계층을 갖는 독립 디자인.
- 사용하지 않은 것: 공식 로고 이미지, 공식 사진, 로그인/SSO 화면, 공식 행사인 것처럼 보이는 문구.

## 3. HYCU UI 규정

- 주소: https://www.hycu.ac.kr/user/comm/html/www_UI_12.do
- 확인된 사실: 메인심볼·서브심볼·시그니처 사용 설명과 전용컬러가 안내되어 있습니다.
- 확인된 전용컬러: RGB (0, 157, 232), RGB (255, 169, 82), RGB (221, 221, 221).
- 반영한 범위: 위 세 색을 `tokens.css`의 `--hycu-blue`, `--hycu-orange`, `--hycu-gray`로 기록했습니다.
- 주의: 공식 심볼을 재현하거나 공식 페이지로 오인할 수 있는 헤더·로그인 화면은 만들지 않았습니다. 나머지 색상과 도형은 이번 특강을 위한 독립 디자인 토큰입니다.

## 4. 사용자 제공 이미지

- 사용한 자료: HYCU 한글·영문 시그니처 이미지, 메인·서브심볼 이미지, 캠퍼스 공간 사진 모음, 한돌이·한순이 이미지.
- 사용 위치: 상단 브랜드 영역, 히어로 사진 모음, 진행표, 마무리·하단 안내.
- 사용하지 않은 자료: `★ 엠베스트_엘리하이에서 진행중인 이벤트.jpg`는 특강 내용과 무관하고 제3자 홍보물로 보여 페이지에 넣지 않았습니다.
